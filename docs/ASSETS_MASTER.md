## How to use this list
1. Make the images in this order: characters first (each character's **model sheet** first, then its poses with the sheet attached), then buildings and places, then shared props and scenery, then thought vignettes. The game draws a simple placeholder for anything not made yet, so any order works. "Extra props (later)" are objects the staging mentions that the game does not place on stage yet.
2. Paste the **style block** first in a new image conversation (or the generator puts it in front of every prompt).
3. Save each image under its file name (the path in `source/ai/`). Characters drawn facing left; the game mirrors them.
4. Reject anything with grey wash, colour, text, a border or a cropped figure.

```
I'm making art for a game based on Mary Shelley's Frankenstein (1818), staged as a Regency-era paper toy theatre. Everything must look like an early 19th-century steel or wood engraving, in the manner of Theodor von Holst's 1831 frontispiece for the novel.

Style rules for every image in this conversation:
- Black ink on pure white paper. Shading ONLY with engraved lines: parallel hatching, cross-hatching, stipple and short flicks. No grey wash, no gradients, no colour.
- Gothic and Romantic in mood: deep night shadows built from dense cross-hatching, strong light from candles, moon or lightning.
- Period accuracy: the 1790s (Geneva, Ingolstadt, the Alps, Scotland, Ireland, the Arctic). High-waisted gowns, tailcoats, cravats, breeches and boots.
- One subject per image, whole and uncropped, with clear white space around it so it can be cut out (unless I ask for a full-frame background).
- No text, no signature, no frame or border.

Reply "ready" and wait for my first request.
```
